# Employee Management App

An Android app built during the Cognifyz Technologies Android Development Internship.

## Features
- Add employees with name, email and department
- Form validation (required fields and valid email)
- Employee list shown with RecyclerView
- Data saved permanently using SQLite
- Slide animations between screens

- Task 6: Simple Form
- Task 7: Basic Database Usage (SQLite)
- Task 8: Implement Navigation
